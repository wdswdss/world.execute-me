# 项目 brief（只写一次）

把下面整段作为"系统提示"或第一轮消息发给要写场景的 agent。
`<>` 里是按你的项目填的。**约束比目标重要**——它决定了你后面会不会一天返工三次。

---

```
我们要用纯代码画一支 MV，不用任何素材、不用任何生成图片/视频。

目标：<歌名 / 时长 / 大致气质>，最终成片 <1920×1080 或 3840×2160> @ 60 fps。

技术底座（已存在，不要改）：
- 192×60 的字符网格；舞台 45×192（STAGE_Y=2 起），格子 10×18 px
- 每帧 = 每格一个字符（索引）+ 前景 RGB + 背景 RGB
- engine/ 里有 frame.py（Frame：paint_mask / paint_mask_colored / paint_text / box）、
  palette.py（颜色与色阶）、widgets.py（面板/进度/折线）、art.py（掩码造型）、fx.py（缓动/噪声）、
  font.py（字符 -> 覆盖率掩码，带缓存）、post.py（CRT 后处理）、chrome.py（页眉/走带条/字幕条/页脚）、
  sceneapi.py（调度 + Ctx）
- 场景就是一个文件：engine/scenes/sNN_name.py，实现 draw(ctx) -> Frame(45, 192)

硬约束：
1. 场景只画舞台 45×192。页眉、走带条、字幕条、页脚一律由 chrome 负责，场景不许碰。
2. 只用 numpy + Pillow。禁止联网、禁止读外部图片/视频、禁止把生成图贴上去。
3. 时间只从 ctx 拿（ctx.t / ctx.beat_i / ctx.bar_i / ctx.pulse / ctx.bands），不许 time.time()。
4. 随机数只用 ctx.rng(seed)：它按帧号播种，保证任意一帧能单独重渲且结果一致。
5. 场景内不得有跨帧可变状态（渲染是多进程按帧并行的）。
6. 文字掩码要缓存（F.text_mask 自带缓存），每帧不要重复光栅化大段文字。
7. 颜色从 palette.py 取，不要随手写 0-255 的魔法 RGB。
8. 性能预算：1080p 一帧 ≤ 0.8 s（8 核并行时整片 ~45 分钟）。

验收：
- 每个场景交付 t = t0+0.4 / 中点 / t1-0.3 三张 1080p 静帧（tools/still.py）
- tools/check_timeline.py 在该区间抽样跑通：0 异常、0 NaN、EN 行无 CJK、字形全部有掩码
- 报告里写清楚"这一帧由哪几层构成"（背景/主体/读数）

先不要动手写代码：先复述你对约束的理解，再给出第一个场景的分层方案。
```

## 为什么这样写

| 条款 | 不写会怎样 |
|---|---|
| 舞台边界 | 场景画到页眉，和 chrome 的字叠在一起，像印糊了 |
| 不许素材 | agent 会"贴心"地生成一张图贴进去，整片风格立刻不一致 |
| `ctx.rng` | 多进程渲染同一帧结果不同，拼接处抖 |
| 无跨帧状态 | worker 之间互相污染，重渲区间对不上 |
| 掩码缓存 | 4K 渲染从 1.7 fps 掉到 0.3 fps |
| 性能预算 | 写完才发现整片要渲 6 小时 |
