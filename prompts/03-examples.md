# 三个真实 spec（这支 MV 里实际跑过的）

不是示意，是从项目里回填的。注意它们的共同点：**固定文案逐字给、运动按时间切片、
验收帧写死**。

---

## s03 infinity（29.730–44.500 s，4 个阶段）

```markdown
**歌词**：If I approach infinity, then you can be my limitations / 若我趋近无穷，你便能成为我的界限
**一句话**：机器用几何图解释"趋近"——先是点阵，再是圆、正弦、极限曲线，最后收成一个 ∞

**分层**
- 背景：深空底色 + 稀疏星点 + 横向扫描线
- 主体：中央一个 ∞（90×22 格），笔画由 ░▒▓█ 填充，带红/青色散副本
- 读数：左上「APPROACH INFINITY」面板（n / |f-L| / x / lim f(x) = L）；
        右上「MY LIMITATIONS」面板（# BOUND 1…5 / count = 5 / 5）
        底部 LIMIT 大字（34 行起）、LIMIT 曲线（33 行）

**运动**
- 0.0–3.692 s：点阵逐渐连成圆
- 3.692–7.385 s：圆展开成正弦
- 7.385–11.077 s：正弦塌成极限曲线
- 11.077–14.770 s：∞ 出现并常亮；亮度沿曲线环流（一条亮带绕行，0.55 周/秒）

**颜色**：主 P.gold → P.white（按环流亮度）；色散副本 P.teal / P.red，不透明度 0.3
**约束**
- ∞ 的尺寸从出现到结束**完全不变**（这是硬要求，之前放大吞屏被否过）
- 读数面板文案逐字固定，不许自己编
**验收静帧**：t = 30.1 / 41.8 / 44.4
**通过标准**：41.8 与 44.4 两帧的 ∞ 行长一致；面板文案与 spec 一字不差
```

## s15 count（147.880–162.650 s）

```markdown
**歌词**：Ein, dos, trois, 넷, fem, 六, execution / 一、二、三、四、五、六，执行
**一句话**：机器逐个数执行次数，数到 6 就执行

**分层**
- 背景：暗红底 + 细网格 + 顶部频谱
- 主体：三块大读数（左 LANG 语言代码、中 COUNT 单词大字、右 INDEX 序号）
- 读数：LANGUAGE BANK 表（6 行，逐行点亮）、SYNTHESIS BUS 进度条、
        COUNTER 面板（count/base/clock/next）、底排 6 个语言卡片

**运动**
- 147.880–158.833 s：`EXECUTION ×4` 蓄力，每小节把 count 推到下一次
- 148.0 s 起每 ~0.35 s 换一种语言：DE → ES → FR → KO → PT → ZH，
  切换时中间大字用"打字机"式替换，卡片同步高亮
- 158.957–161.730 s：报数句（6 种语言混排）
- 161.730–162.650 s：空档，只留读数

**颜色**：主 P.red（告警红）+ P.amber；每语言一个强调色（从 palette 取，不新造）
**约束**
- 语言代码必须用官方拼写：DE/ES/FR/KO/PT/ZH，单词 ein dos trois 넷 fem 六
  （早期版本把 넷/六 罗马化成 ne/liu，被否过——理由：那不是原版）
- 中文字幕行不许混进英文行
**验收静帧**：t = 152.0 / 159.6 / 161.5
**通过标准**：161.5 的 6 个卡片全部 SYNTH；中间大字是当前语言词
```

## s21 endtext（206.960–211.905 s）

```markdown
**歌词**：（无，纯音乐 + 打字）
**一句话**：机器执行完就安静了，屏幕上只剩一行打出来的话和一个光标

**分层**
- 背景：几乎全黑，只留极弱的扫描线
- 主体：中央一行打字机文字（逐字符出现，带轻微字符抖动）
- 读数：极小的角落状态（可省略）

**运动**
- 206.960–207.4 s：上一段的残影熄灭
- 207.4–209.6 s：逐字打出主句
- 209.6–211.905 s：光标闪烁，画面几乎不动

**约束**
- 不许有音乐性的动效（这一段要"安静"）
- 光标闪烁必须对齐节拍（用 ctx.beat_p，不是 time）
**验收静帧**：t = 207.2 / 209.0 / 211.5
**通过标准**：三帧的字数递增；光标在两帧里相位不同
```

## 从这三份里能看出的模式

1. **每段都有"读数"层**：这支 MV 的"界面感"来自边角始终有 HUD，不是主体自己在动。
2. **运动一律按小节切**：0-3.7 / 3.7-7.4 这种刻度就是 130 BPM 下的小节长度。
3. **被否过的方案写在 spec 里**（"早期放大吞屏被否"、"罗马化被否"），
   这样换一个 agent 接手也不会退回去重犯。
